# 术语便签与交互原型：使用方式与安全边界

本文说明课程内容新增的两种 Markdown 组件。设计原则：**正文保持完整可读，少量术语解释按需出现；复杂动态机制使用可访问的独立页面，而不是在含有 GitHub PAT 的管理后台执行任意第三方代码。**

## 术语聚焦便签

编辑后台 /admin/ → Markdown 工具栏 → **术语便签**。先选中原有术语，点击工具，填写短解释并插入。也可手工编写：

~~~markdown
HDFS 的 :term[NameNode]{note="负责命名空间和块元数据，不转发全部文件数据。"} 保存元数据。
~~~

限制：术语最多 80 字、解释最多 320 字。正文仍展示普通的短词，解释只在鼠标悬停、聚焦或触屏激活时出现。

- 鼠标：悬停显示，移入卡片后仍保持展开，**支持选中说明文字并使用系统快捷键复制**；
- 键盘：Tab 聚焦，Enter / Space 可打开，Esc 关闭；
- 触屏：点击术语显示，可长按卡片文字选中，点击正文其他区域关闭；
- 无 JavaScript：CSS 保留 hover / focus 基础功能；
- 无脚本、远程请求或动态数据库；
- 便签是简要辅助说明，核心推导应保留在正文。

语法只接受纯文本。解释内不支持任意 HTML、链接、图片或执行代码。Markdown 插入弹窗为稳健解析限制部分定界符，复杂引号请在正文中另行说明。

## 原型卡片

后台 → Markdown 工具栏 → **原型卡片**，填入标题、简短说明和原型链接。也可手工写：

~~~markdown
:::prototype{title="HDFS 写入四步演示" href="/demos/hdfs-write/"}
按照步骤解释 NameNode 和 DataNode 的协调机制。该原型不连接真实集群。
:::
~~~

这会显示一个带标题和说明的普通链接卡片。只允许 HTTPS 地址或者本站以单个斜线开头的绝对路径，阻止 javascript:、data:、file:、protocol-relative（双斜线）链接。

**不允许通过术语/原型功能执行第三方 JavaScript、第三方 iframe 或任意 HTML。** 后台预览仍是 opaque-origin iframe（无 `allow-same-origin`），内容经过 HTML 清理，CSP 仅允许运行本站固定 `/admin/preview-height.js`。该脚本只汇报完整预览的高度或左右对照的滚动进度（0–1），不读取/发送文章正文、GitHub Token 等数据，也不能访问父页面 DOM。原型卡片继续只提供安全链接。

### 为什么不做真正的“拖拽式原型编辑器”？

拖拽原型需要组件画布、持久化布局数据、图层资产、事件系统以及复杂的脚本安全隔离，会显著扩大 /admin/ 的攻击面和前端加载成本。当前博客主要用于技术写作，对每篇文章引入这一套工具收益不高。

因此采取渐进式方案：

1. **轻量级**：文字、表格、SVG 等静态图直接用 Markdown/图片上传，已支持；
2. **交互性强**：单独构建受审查的 Astro/TypeScript 可视化页面，再由原型卡片链接；
3. **外部可用资源**：取得授权且核对内容后，链接外部原型而非复制执行代码；
4. **未来扩展**：若确实需要原位嵌入，应先设计独立 origin/sandbox、严格 CSP、内容签名与大小预算，在安全审查通过后另行实现。

仓库提供的示例原型位于 /demos/hdfs-write/，包含四个步骤、键盘按钮与减少动态效果支持，无任何外部网络依赖。它展示的是抽象协议模型，不是实际环境测试结果。

## 引用与图片版权

- 引用讲义、公开 CS 课程、官方文档时保留资料标题和来源；
- 原讲义中的受保护图片不直接复制到仓库；
- 第三方图片只有在核实可复用许可及署名要求后才上传；否则使用外链或重新绘制；
- 自制图表应保留可编辑源文件，避免后续只能修改截图。

## 手工验收矩阵

- 桌面 Chrome / Firefox / Safari：hover、Tab、Enter、Escape、页面滚动和弹层不遮挡主要操作；
- Android / iOS 触屏：点击术语、点击外部关闭、小屏底部弹层不超出视窗；
- 深浅主题、中文 / EN 切换、减少动态效果模式；
- 后台编辑/预览切换、左右对照、插入后撤销重做；
- 测试含尖括号、链接协议、引号和异常长度的数据，确认没有脚本执行与意外外链；
- 课程草稿保持 draft:true，不出现在公开页面、搜索与 RSS；
- npm test、npm run check、npm run build 和真实浏览器端到端验证。

如果未运行以上某项，不应报告该项 PASS。
